This Java application implements a simple Product Management System using a console-based interface.
Users can perform CRUD operations (Create, Read, Update, Delete) on products.

Features :
Add Product – Enter product name, price, and quantity to add a new product.

View Products – Display a list of all products.

Update Product – Modify details of an existing product using its ID.

Delete Product – Remove a product using its ID.

Exit – Close the application.
